# Contributing

MHSB Solutions repositories are **reference implementations** for applied AI in regulated legal work. Contributions that improve correctness, security, determinism, or clarity are welcome.

- Open an issue before large changes.
- Include tests/evals where the repo has them; keep changes focused.
- Never include client, matter, or personal data anywhere (code, tests, fixtures, issues).
- Security issues follow [SECURITY.md](SECURITY.md), not public issues.
